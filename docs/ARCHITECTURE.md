# Architecture
Static PWA with hash navigation and GitHub Pages base. `src/main.tsx` owns shell/navigation; `src/features/` contains dashboard, onboarding, missions, explorer, journal, progress and settings routes; `src/components/shared.tsx` contains shared UI and local-record reads. `src/features/missions/engine.ts` contains deterministic curated missions and pure timestamp transitions. `src/db/repository.ts` defines/version-migrates Dexie tables, photo compression and validated backups. `src/ai/` contains prompt catalog/cosine math and lazy inference/cache adapter. `src/styles.css` supplies mobile-first layout, original SVG presentation, system motion preferences and themes.

IndexedDB: observations by ID/date/category/missionId; sessions by ID/missionId/status/completedAt. Export covers observations and embedded photo data URLs, not mission sessions. Import validates every row before transactional writes; refuses existing IDs to prevent accidental overwrite. Notes render as React text, never HTML. Quota errors remain visible rather than claiming success.

Service worker: precaches generated static shell and same-origin ONNX runtime. AI Cache Storage: required config/tokenizer/two encoder artifacts keyed by pinned Hugging Face URL. Cache completeness and actual runtime execution are different checks. Preparation only reports AI success after model load and text inference. Clearing AI removes its cache and loaded adapter. No GPS tracking, telemetry, account or backend.

Session completion is explicit user confirmation. Time is elapsed active wall-clock timestamp segments; pause stores accumulated milliseconds. Resuming after sleep derives duration from persisted timestamps. UI interval is display only. Screen-free mode minimizes mission interactions; device sleep may suppress live vibration.
