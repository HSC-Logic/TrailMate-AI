# TrailMate AI: Explore More. Scroll Less.
This is a submission for the Hacktoberfest Open-Source AI Challenge Week 1: Touch Grass.

## What I Built
An offline-first, private outdoor PWA with twenty gentle nature missions, a local photo journal, and genuine on-device CLIP candidate ranking. Initial audience includes students, families and casual explorers in Sri Lanka. Completion and outdoor time are user-reported.

## How I Built It
React, TypeScript, Vite, Tailwind, IndexedDB and Workbox. Transformers.js runs open-weight CLIP text/image encoders in browser WASM. Explicit download provisions pinned model artifacts; photos stay on-device. Similarities are educational category suggestions, not probabilities or species identification. Hash navigation and repository base support GitHub Pages.
[Measured browser benchmarks: PLACEHOLDER]
See repository validation records for actual passes and remaining gaps. No field-testing claims until recorded.

## Why Does Open Innovation Matter?
Open weights let the community inspect, reproduce, replace and improve the model. Local inference protects photo privacy, avoids recurring API fees, and supports offline exploration once downloaded. Transparent artifacts and reproducible tests make contributions practical rather than dependent on a closed cloud service.
