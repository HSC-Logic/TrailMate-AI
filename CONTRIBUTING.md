# Contributing
Use Node 24+. Run `npm ci`, `npm run dev`. Before a PR: typecheck, lint, unit tests, build and Playwright. Keep photos on-device, imports validated, prompts educational, permissions optional. Never replace inference with fake labels or turn similarity into probability.

Useful contributions: accessible missions, Sri Lanka safety guidance, mobile WASM measurements, model-license evidence, translations, storage recovery. Discuss new dependencies or models in an issue first. Include actual test results and mark unverified capabilities. Do not submit personal photos or exact locations. Original contributions use MIT.
